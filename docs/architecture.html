Trader's Agent Plugin — Architecture

Hermes Desktop plugin · Vela console · LuxAlgo MCP — the command path from chat composer to candles

How a session invokes it

  • • MCP “traders-chart” is global in Hermes config — a brand-new session already has all 28 chart tools
  • • No /tradersagent command exists or is needed; the sidebar row only reveals the pane
  • • Reveal never changes your chat session, then bounces focus back to the composer
  • • Pane is defaultCollapsed — it never opens itself (standing rule)

Command lifecycle (one request)

  • • chat → MCP tool → POST /command (preflight gate) → SSE push → first claim wins → run → result → one sentence back
  • • Preflight reads the 4s heartbeat: age_s > 10s refuses in milliseconds, queue untouched
  • • Window maths: inline wait 8s · reads 5–6s · gate 10s · stale-warn 30s · dead 300s
  • • Wedged console = sentence, never a traceback (raw TimeoutError handled)

Ground rules the tests enforce

  • • Hermes-only UI: every “open in a browser” exit removed, absence pinned by test
  • • One indicator per chart at a time — apply, screenshot, then the next
  • • Vela Apache-2.0 + PineTS AGPL stay on the CDN — nothing vendored into the repo
  • • SMC reference (CC BY-NC-SA) sits off the import path, license intact
