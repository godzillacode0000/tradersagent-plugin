tradersagent-plugin — Architecture

Hermes Desktop plugin · chat-driven Vela chart console + LuxAlgo Library, controlled through 28 MCP tools

Repo layout

  • • plugin/plugin.js — 5 contributions: routes, panes, sidebar.nav, statusBar, palette
  • • console/frontend — Vela chart, chart-bridge.js, pinets-runner, Library panel
  • • console/backend — console server + the 111-test suite (stdlib & fastmcp)
  • • console/mcp — 28 chart_* tools over FastMCP stdio
  • • skills/trader-desk — desk skill · install.sh + tools/ — doctor, sync, harness

Control path (prompt → chart)

  • • Chat prompt → Hermes Agent → MCP client → console/mcp (stdio)
  • • Tool call → loopback REST/WS → console backend → chart-bridge → Vela
  • • State flows back the same pipe: heartbeat every 4s + live probe on read
  • • Guards: add dedup · remove-all ledger · freshness warnings · switch deadline

Choices that shape it

  • • One composer — the app's own; the sidebar row reveals the pane and bounces back (22 Sep)
  • • Vela + PineTS from CDN, never vendored (AGPL-3.0-only)
  • • LuxAlgo studies CC BY-NC-SA — code lives in docs/studies, not the build
  • • No orders ever · PineTS subset (no import, no while) · Linux/Omarchy only · pane contributes collapsed
